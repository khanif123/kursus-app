Panduan Setup

Aplikasi Kursus Bahasa Inggris

0 dari 10 langkah selesai

1

Buat akun Supabase

Ini database gratis untuk aplikasi kamu. Daftar pakai email atau GitHub.

Buka Supabase
2

Buat project baru

Di dashboard Supabase, klik "New Project". Isi nama bebas, buat password database, pilih region terdekat (contoh: Singapore). Tunggu 1-2 menit.

3

Salin kode database

Klik tombol di bawah untuk menyalin kode. Lalu di Supabase, buka "SQL Editor" → "New query", tempel (paste) kodenya, klik "Run".

4

Salin kode Panel Admin

Sama seperti sebelumnya: salin, buka "SQL Editor" → "New query" lagi, tempel, klik "Run".

5

Catat kunci API

Di Supabase, buka "Project Settings" (ikon gear) → "API". Catat/screenshot dua hal: "Project URL" dan "anon public key". Nanti dibutuhkan di langkah 8.

6

Buat repository GitHub

Buat repository baru (nama bebas), lalu upload semua file dari folder "kursus-app" ke situ.

Buka GitHub — Buat Repo
7

Buat akun Vercel

Daftar gratis, paling gampang pakai akun GitHub yang sama.

Buka Vercel
8

Deploy aplikasi

Di Vercel, klik "Add New → Project", pilih repository GitHub kamu. Sebelum klik Deploy, buka "Environment Variables" dan tambahkan 2 baris:
NEXT_PUBLIC_SUPABASE_URL = Project URL dari langkah 5
NEXT_PUBLIC_SUPABASE_ANON_KEY = anon public key dari langkah 5
Lalu klik "Deploy". Tunggu 1-2 menit sampai online.

9

Daftar akun untuk dirimu sendiri

Buka link aplikasi kamu yang sudah online (dari Vercel), klik "Daftar di sini", buat akun pakai email kamu.

10

Jadikan dirimu Super Admin

Di Supabase → "Table Editor" → tabel "profiles". Cari baris dengan namamu, ubah kolom "role" jadi super_admin, simpan. Login ulang ke aplikasi — tombol "Buka Panel Admin" akan muncul.

Ini langkah manual terakhir. Setelah ini, semua dikerjakan langsung dari website.
